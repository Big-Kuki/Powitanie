# Powitanie
Aplikacja napisana w języku Java na system Android (minSdk 24).

## Wybór szablonu
Wykorzystałem szablonn "Empty Views Activity", ponieważ bazuje on na tradycyjnym podejściu z wykorzystaniem plików XML (View System) oraz języka Java, a Szablon "Empty Activity" domyślnie korzysta z nowszego frameworka "Jetpack Compose" do deklaratywnego budowania interfejsu w języku Kotlin.
